## 这是什么

曾经的 Community Labs：围绕官方 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 内核做 Bridge、SDK、安全、Checkpoint、审计、实验性 TUI/Desktop 和 Android 原型。

它从来不是第二个客户端。本仓不会再把包发到 npm `latest`。树里最后一次 Labs 完整验证线是 `@deepseek-ai/dsh@0.1.1-rc.2`。
