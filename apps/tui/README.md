# `@dsh-community/tui`

社区终端入口。官方 `@deepseek-ai/dsh` 是 Runtime。

**不安装、不挂** `@deepseek-harness-tui/dsh-tui`。第三方 TUI 只许参考，不是产品。

启动：

```text
dsh --profile headless --patch <community overlay>
```

```sh
dsh-community
dsh-community new "任务"
dsh-community sessions
dsh-community doctor
```

Session 仍在官方 `~/.dsh`。
