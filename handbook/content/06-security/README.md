# 安全使用

dsh 的安全不是一个开关，而是权限、沙箱、workspace、Provider、工具、日志和人工审批共同形成的边界。

## 四个必须分开的问题

1. Agent 被允许请求什么；
2. 进程实际上能访问什么；
3. Provider 和外部工具会收到什么；
4. 任务结果怎样被外部验收。

一个问题回答“允许”，不等于另外三个问题也安全。

## 默认原则

- 从最小权限开始；
- 从只读 workspace 开始；
- 从临时或可恢复副本开始；
- 从新 session 开始；
- 先写停止条件，再批准高影响动作；
- 先保存脱敏现场，再清理或回滚；
- 不用代理的最终回答替代人工验收。
