# 自动化安全

自动化脚本本身也是权限边界。审查脚本时，和审查 Agent prompt 一样认真。

## 输入来源

把任务来源分类：

- 代码仓库内的固定模板；
- 受控工单字段；
- 用户自由文本；
- 网页或 Issue；
- 其他 Agent 生成的文本。

来源越不可信，越不能直接给它写入、联网或高权限能力。

## 命令注入

不要用字符串拼接形成 shell 命令。对任务 ID、路径、模型 ID 和外部文本：

- 限制字符集；
- 使用进程参数数组；
- 使用绝对路径；
- 禁止把外部文本解释成额外参数；
- 对生成的任务文本设置长度和字段边界。

## 日志

自动化日志至少记录版本、任务 ID、session ID、退出码和验收状态，默认不记录：

- API key；
- 完整环境；
- 私有源码；
- Cookie；
- Authorization header；
- 未脱敏任务原文；
- 完整模型输入输出。

## 自动修复策略

当任务失败时，自动化可以收集信息和阻断流水线，不应自动执行：

- 提高权限；
- 删除工作区；
- 安装依赖；
- 重复不可逆命令；
- 将数据上传到另一个 Provider；
- 切换到不受批准的模型。
