## 工具的三层

~~~text
工具 schema：模型知道什么名字、参数和描述
工具执行：dsh 把调用交给哪个服务/后端
外部结果：文件、进程、网络和 session 实际发生什么
~~~

模型可见不等于执行成功，执行成功也不等于任务合规。验收要回到外部结果。

## 工具使用原则

- 先知道当前 profile 加载了什么；
- 先读后写，先小范围后大范围；
- 对命令、路径、网络和后台任务逐项确认；
- 把工具失败当作真实状态，不要让模型用文字覆盖；
- 高影响工具必须有审批、回滚和独立验收。
