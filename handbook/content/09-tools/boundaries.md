# 工具边界排查

## 工具不可见

检查：

- 当前 profile 是否包含工具包；
- 组合是否被 patch 替换；
- workspace/session 是否初始化；
- 模型是否看到对应 schema；
- 工具是否被平台或权限禁用；
- 是否使用了 Web、headless 或 SDK 的不同入口。

## 工具可见但被拒绝

区分：

- schema 参数错误；
- 权限/审批拒绝；
- 沙箱拒绝；
- Provider 不支持输入；
- 文件路径不存在；
- 进程启动失败；
- 用户未回答询问。

每个层级的修复不同，不要只提高权限。

## 工具成功但结果不对

检查：

- 工作目录；
- 实际命令；
- 环境变量；
- 退出码；
- 输出是否截断；
- 文件是否更新；
- 后台进程是否仍在运行；
- session 是否将结果关联到当前任务。

工具名称：
