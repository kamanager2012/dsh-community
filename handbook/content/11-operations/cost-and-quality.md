# 成本、质量与人工介入

## 不要只看成功率

Agent 任务的质量至少有：

- 目标完成率；
- 外部验收通过率；
- 范围违规率；
- 人工介入率；
- 重试率；
- 平均/尾部耗时；
- 每任务 token 或费用；
- 遗留进程和清理失败；
- 结果可解释性。

模型说成功但测试失败的任务不能计入真正成功。

## 质量样本

团队可维护一组固定但不虚构结果的任务样本：

- 只读目录导览；
- 已知测试失败；
- 小范围编辑；
- 文档更新；
- Provider 配置错误；
- 权限拒绝；
- 超时和取消；
- session 恢复。

样本定义任务和验收，不预先填“模型应该得到的答案”。实际运行后单独记录结果。

## 预算

预算至少包括：

~~~text
每任务最大时间：
每任务最大 token/费用：
最大工具调用：
最大并发：
最大重试：
最大 workspace 大小：
人工暂停阈值：
~~~

超出预算进入人工处理，不自动换高权限或更贵模型。

## 质量回归

升级 dsh、Provider、模型或 profile 后，使用同一批任务重新检查：

- 工具是否仍然加载；
- 权限和审批是否变化；
- 结果和退出码；
- diff 是否超范围；
- session 是否能清理；
- 日志是否出现新敏感字段。

这类回归要记录真实结果；没有运行就写“待复核”，不要伪造通过。
