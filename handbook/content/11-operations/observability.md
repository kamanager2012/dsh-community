# 日志与可观测性

## 观察什么

一次运行至少有四条时间线：

~~~text
进程时间线：启动、退出、子进程
Agent 时间线：turn、step、请求、停止
工具时间线：调用、审批、执行、结果
工作区时间线：文件、diff、测试和产物
~~~

把它们只压缩成最终文本，会丢掉排错最需要的信息。

## 关联 ID

推荐用内部任务 ID 关联：

- 业务任务；
- dsh 进程；
- session；
- workspace；
- Provider 请求；
- CI 构建；
- 验收结果。

ID 不要包含密钥、完整路径或用户输入。

## 指标

可以观察：

- 启动成功率；
- 缺凭据和配置失败率；
- Agent 完成率；
- 工具失败率；
- 验收通过率；
- 平均和尾部耗时；
- 重试率；
- 人工介入率；
- 每任务 token/成本（若 Provider 提供）；
- 遗留进程和 workspace 数。

指标用于发现回归，不应被模型自行生成。

## 脱敏

日志处理时扫描：

- key/token；
- Authorization；
- Cookie；
- 私有路径；
- 个人信息；
- 私有代码片段；
- 原始任务文本；
- 图片和二进制附件。

脱敏要在写入共享日志前进行，不要先上传再删除。

## 告警

重点告警：

- 非预期权限升高；
- Provider 或模型突然变化；
- 连续 MISSING_CREDENTIAL/401；
- 工具调用异常增加；
- 任务结束但子进程仍在；
- workspace 清理失败；
- 验收失败而 Agent 大量报告成功。
