## 复制前先确认

- 当前入口是 Web、headless、SDK 还是源码；
- 当前版本的 --help 是否仍然支持该命令；
- 示例是否包含 placeholder；
- workspace、权限和 Provider 是否已经替换；
- 模板中的禁止项是否适合当前任务；
- 验收命令是否真的存在。
