# 阅读计划

如果想按一本书连续阅读，先看根目录的 [BOOK.md](../../BOOK.md)；下面的路线适合按角色缩短阅读范围。

## 个人第一次使用

读：

1. [五层模型](../00-overview/harness-five-layers.md)；
2. 安装与首次启动；
3. Web UI 首次任务；
4. [主线实战](../05-workflows/from-blank-to-delivery.md)；
5. DeepSeek Provider；
6. 只读工作流；
7. 结果复核；
8. FAQ。

读完应该能在可恢复 checkout 中完成一条从基线到验收的受控任务，并知道什么时候停、什么时候换 session。

## 开发者

读：

1. 心智模型；
2. 架构；
3. 源码开发；
4. Cordis 入门；
5. 工具执行流水线；
6. 插件模型；
7. Cordis 实践教程；
8. 插件调试与发布。

读完应该能选择扩展 seam，并写出权限、数据流、teardown 和兼容性说明。

## 自动化操作者

读：

1. CLI 命令；
2. Profile 与配置；
3. Headless；
4. SDK 结果与错误；
5. 批处理与隔离；
6. CI；
7. 日志与可观测性；
8. 任务队列和重试。

读完应该能让退出码、外部验收和清理控制流水线，而不是只收集一段模型文本。

## 安全评审者

读：

1. 权限；
2. 凭据；
3. 数据流；
4. 威胁模型；
5. 审批操作手册；
6. 团队安全评审；
7. 事故响应；
8. 发布检查清单。

读完应该能对一个 profile 或任务给出通过、有条件通过、不通过或待补充结论。

## 维护手册的人

每次更新前读[官方来源与阅读方法](sources.md)，再按受影响入口查官方 README、用户指南、CLI、工具目录、架构和开发指南。不要只改一页命令而不更新相关模板、FAQ、版本说明和导航。
