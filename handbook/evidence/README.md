# Evidence records

这里保存经过脱敏的 Evidence Record、摘要和产物索引，不保存秘密或未经处理的原始会话。

每条记录至少回答：

1. 这是规范、实现、观察、分析还是方法启发？
2. 它对应哪个版本、commit、平台和日期？
3. 运行了什么命令，输入和 workspace 是什么？
4. 结果是什么，是否可重复？
5. 有哪些限制，影响哪些文档？

F0、F1、F2 出现不一致时，记录不一致本身；不要用一个标签覆盖另一个标签。

主题级依赖关系见 [`source-matrix.yaml`](source-matrix.yaml)。矩阵不是新的事实来源，而是防止正文引用遗漏和状态误判的索引。
