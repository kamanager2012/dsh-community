# WEB-BOOT-2026-08-14

这是 Web 服务启动层的 F2 探针，不是端到端 Web UI Lab。

## 命令

```sh
DSH_HOME=/tmp/dsh-handbook-web-boot-rc6 \
  timeout 20s npx --yes @deepseek-ai/dsh@0.1.0-rc.6 web --port 0
```

## 观察结果

进程输出：

```text
dsh web: http://127.0.0.1:43533
```

随后由外层 `timeout 20s` 按预期停止长驻服务，退出码为 `124`。这里的通过条件是“在随机端口打印启动 URL”，不是“命令自然退出为 0”。

本记录证明：固定发布包可以进入 Web profile 并完成启动公告。它不证明浏览器能够加载页面，也不证明模型、Provider、workspace、Trajectory 或任务执行正常；这些仍由 `LAB-BOOT-001` 负责。

对应 YAML 记录：[`WEB-BOOT-2026-08-14.yaml`](WEB-BOOT-2026-08-14.yaml)。
