# WEB-HTTP-2026-08-14

这是固定发布包 `@deepseek-ai/dsh@0.1.0-rc.6` 的 HTTP 层 F2 探针。

## 执行

先启动本机服务：

```sh
DSH_HOME=/tmp/dsh-handbook-http-rc6 \
  npx --yes @deepseek-ai/dsh@0.1.0-rc.6 web --port 3081
```

在服务运行期间执行：

```sh
curl --silent --show-error --max-time 5 \
  --dump-header - http://127.0.0.1:3081/
```

## 观察结果

```text
HTTP/1.1 200 OK
content-type: text/html; charset=utf-8
<title>DeepSeek Harness</title>
```

随后用 `Ctrl-C` 主动停止服务。这个记录只证明 HTTP 根路径能返回 HTML shell；它不证明浏览器渲染、模型配置、workspace、session、Trajectory 或任务执行正常。
